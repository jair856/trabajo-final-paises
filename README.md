Trabajo Final 
En grupos de 2 a 3 alumnos, deben colaborar para crear un proyecto que recopile 
información de los países del mundo 
Se debe crear un repositorio en github y añadir a los miembros del grupo. 
En el primer commit el propietario del repositorio en github debe crear el archivo 
README.md en donde copiará todas las instrucciones de la tarea compartidas en este 
documento y en la parte final inferior del texto, el nombre de los integrantes del grupo, el 
mensaje para este commit es “Commit Inicial” y se debe hacer sobre la rama “main”. 
Todos los integrantes del grupo deben clonar este repositorio y empezar a agregar features 
bajo las siguientes condiciones. 
• Crearse una rama con el nombre del integrante si es que no se ha creado todavia, 
esta rama debe tener como rama padre a la rama “main” 
• Anotar el nombre de 6 países (2 de cada continente), cada país debe ir en un 
archivo con el nombre del continente (america.txt, asia.txt, africa.txt, europa.txt, 
oceania.txt) 
• Asegurarse que las listas estén ordenadas alfabéticamente y no haya países 
repetidos 
• El mensaje para el commit será “feat: (1er-2do, 3er, 4to, etc…) grupo de países 
agregados por (nombre del alumno)” Repetir esto 2 veces y fusionar con la rama 
“main” utilizando un commit de fusión con el mensaje “fusionando con rama 
principal”  [AYUDA: para esto nos ubicamos en la rama “main” con el comando (“git 
switch main” o el comando “git checkout main” ) y ejecutamos el comando git 
merge –no-ff <Nombre de la rama a fusionar>] 
• Repetir esto hasta que cada continente tenga 12 países en su archivo 
correspondiente  
Para la revisión deben enviar en el grupo de WhatsApp el link de su repositorio en 
Github
